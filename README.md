QuickChat is a Java console-based chat application. Part one covers registration and login. Part 2 discusses sending messages.
## Features
- Register and login.
- Numeric menu for sending messages
- Messages are kept in messages.json.
- Use JUnit for unit tests.

## How to Run 
1. Open the project in NetBeans 
2. Launch ChatApp.java.
3. Navigate through the console's menu.

 ## How to Test
Run the tests in NetBeans using Maven (Test File).
